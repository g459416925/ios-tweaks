BounceIt16

  1. 给 SpringBoard 系统动画加弹簧回弹：界面冲过头 → 回弹 → 小幅震荡几下才停
  2. hook SBFFluidBehaviorSettings -setDampingRatio: 与 SBFAnimationSettings 的 damping / stiffness / mass / epsilon （两者继承 PTSettings，属性走 getter）
  3. 原版 Bounce It! 的另外 19 个 hook 点在 iOS 16 已全部失效 （相关类已不存在 / 属性被移除），故本插件只挂真实存在的 5 个目标
  4. 手感：阻尼比 ζ ≈ 0.33（过冲 34%、约 0.48 s 收敛）—— 弹 2 下即停； 只调 damping、不动 stiffness（改 stiffness 会改动画节奏）

⚠️ 仅注入 SpringBoard。原版 BounceIt 的二进制在 RootHide 下无法加载 （roothidepatch 破坏 arm64e 切片签名 → dyld 拒绝），故本版为自行重写。

CompactorFix

  1. 原版 Compactor 失效是调用时机太晚，本版改在 dyld 构造函数里调用私有 API
  2. 实测：全部 UI 字体类型 0..24 变为 .SFCompact-*，整屏 13.07% 像素变化
  3. 注入到全部 UIKit App + SpringBoard（Filter.Classes = UIApplication）

⚠️ SF Compact 是拉丁系字体（拉丁/希腊/西里尔，共 1358 码位）， 不含中日韩 → 中文仍回退苹方 PingFang，中文外观不变属预期行为。

ScreenTimeLocker16

  1. 禁止「再使用一分钟」（0 / 0 限额可长期生效）
  2. 允许把限额设为 0 小时 0 分钟
  3. 认证优先走 Face ID，用不了时回落屏幕使用时间密码
  4. 菜单弹窗保持系统原样，不注入额外选项

不隐藏任何原生按钮，「请求更多使用时间」照常保留。宿主进程 SpringBoard。

StatusBarScale

  1. 灵动岛右侧图标比时间大一号且重心偏高 1.66px —— 本插件缩放对齐
  2. hook _UIStatusBarForegroundView -layoutSubviews，每次布局后对命中图标施加 绕中心缩放 + 垂直微调；transform 不参与布局 → 间距与点击区域不受影响， 灵动岛展开自动跟随
  3. 主缩放：frame.minX ≥ 280（灵动岛右缘）的状态栏图标 × 0.9025； 垂直下移按绑定曲线 dy(s)=K·(1−s) 实时推算（当前 0.43pt）
  4. 时间旁缩放：时间右侧、灵动岛左侧那批图标（闹钟/定位/录屏等，无法按标识枚举） × 0.5038；运行时按 fg 坐标系 frame 区间发现，带三道场景门禁 （只处理全屏宽度 fg / 无可视时间跳过 / 岛左缘须在 60~200）
  5. 带撤销/复核：状态栏 item 视图会被系统复用池回收后换身份，脱离命中区间即 「先摘登记、再还原」（防「时间被缩放」）
  6. 参数已硬编码进源码：不含设置面板、不读取任何配置文件
  7. 资源库背景透明（v2.1.0 卡片 / v2.1.1 搜索框）：App 资源库分类卡片的背景板 (SBHLibraryCategoryPodBackgroundView) 与顶部搜索框的背景材质 (SBHSearchTextField 内的 MTMaterialView) 清成透明， 只留图标与文字。⚠️ 搜索框是常驻视图、进资源库不重新布局 ⇒ 需每 2s 主动扫描处理

⚠️ 仅注入 SpringBoard（Filter.Bundles = com.apple.springboard）—— 普通 App / WebKit / PosterBoard 不加载本插件；App 内状态栏由 SpringBoard 远程渲染， 观感一致。

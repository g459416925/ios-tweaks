LeafCrack（Leaf 会员解锁）

  1. 注入 com.kitslabs.production.Leaf，直接写入高级会员状态： LEAF_ENC_IS_PREMIUM_ACTIVATED / TOTAL_POINTS / LAST_DEDUCT_TIME
  2. swizzle NSUserDefaults 的 setBool:forKey: / setInteger:forKey: / setDouble:forKey:，App 想把标记改回去会被强制覆盖
  3. swizzle RevenueCat 的 RCEntitlementInfo / RCEntitlementInfos 的 isActive / active 系列 → 恒返回 YES
  4. 启动后自动确保 LEAF_ENC_DEFAULT_CONFIG_KEY 指向有效配置文件， 否则点 GO 会静默失败（界面停在 Ready to Connect，LeafTunnel 不启动）
  5. 后台巡检 10 分钟，会员标记被覆盖立刻重写

RootHide 注入点在 /usr/lib/TweakInject/， 并带 .roothidepatch 软链指向 AutoPatches.dylib。 装完杀掉 Leaf 重开即生效。

BounceIt16

  1. 给 SpringBoard 系统动画加弹簧回弹：界面冲过头 → 回弹 → 小幅震荡几下才停
  2. hook SBFFluidBehaviorSettings -setDampingRatio: 与 SBFAnimationSettings 的 damping / stiffness / mass / epsilon （两者继承 PTSettings，属性走 getter）
  3. 原版 Bounce It! 的另外 19 个 hook 点在 iOS 16 已全部失效 （相关类已不存在 / 属性被移除），故本插件只挂真实存在的 5 个目标
  4. 手感：阻尼比 ζ ≈ 0.33（过冲 34%、约 0.48 s 收敛）—— 弹 2 下即停； 只调 damping、不动 stiffness（改 stiffness 会改动画节奏）

⚠️ 仅注入 SpringBoard。原版 BounceIt 的二进制在 RootHide 下无法加载 （roothidepatch 破坏 arm64e 切片签名 → dyld 拒绝），故本版为自行重写。

CompactorFix

  1. 原版 Compactor 失效是调用时机太晚，本版改在 dyld 构造函数里调用私有 API
  2. 实测：全部 UI 字体类型 0..24 变为 .SFCompact-*，整屏 13.07% 像素变化
  3. 注入到全部 UIKit App + SpringBoard（Filter.Classes = UIApplication）

⚠️ SF Compact 是拉丁系字体（拉丁/希腊/西里尔，共 1358 码位）， 不含中日韩 → 中文仍回退苹方 PingFang，中文外观不变属预期行为。

ScreenTimeLocker16

  1. 禁止「再使用一分钟」（0 / 0 限额可长期生效）
  2. 允许把限额设为 0 小时 0 分钟
  3. 认证优先走 Face ID，用不了时回落屏幕使用时间密码
  4. 菜单弹窗保持系统原样，不注入额外选项

不隐藏任何原生按钮，「请求更多使用时间」照常保留。宿主进程 SpringBoard。

StatusBarScale

  1. 灵动岛右侧图标比时间大一号且重心偏高 1.66px —— 本插件缩放对齐
  2. hook _UIStatusBarForegroundView -layoutSubviews，每次布局后对命中图标施加 绕中心缩放 + 垂直微调；transform 不参与布局 → 间距与点击区域不受影响， 灵动岛展开自动跟随
  3. 主缩放：frame.minX ≥ 280（灵动岛右缘）的状态栏图标 × 0.9025； 垂直下移按绑定曲线 dy(s)=K·(1−s) 实时推算（当前 0.43pt）
  4. 时间旁缩放：时间右侧、灵动岛左侧那批图标（闹钟/定位/录屏等，无法按标识枚举） × 0.5038；运行时按 fg 坐标系 frame 区间发现，带三道场景门禁 （只处理全屏宽度 fg / 无可视时间跳过 / 岛左缘须在 60~200）
  5. 带撤销/复核：状态栏 item 视图会被系统复用池回收后换身份，脱离命中区间即 「先摘登记、再还原」（防「时间被缩放」）
  6. 参数已硬编码进源码：不含设置面板、不读取任何配置文件
  7. 资源库背景透明（v2.1.0 卡片 / v2.1.1 搜索框）：App 资源库分类卡片的背景板 (SBHLibraryCategoryPodBackgroundView) 与顶部搜索框的背景材质 (SBHSearchTextField 内的 MTMaterialView) 清成透明， 只留图标与文字。⚠️ 搜索框是常驻视图、进资源库不重新布局 ⇒ 需每 2s 主动扫描处理

⚠️ 仅注入 SpringBoard（Filter.Bundles = com.apple.springboard）—— 普通 App / WebKit / PosterBoard 不加载本插件；App 内状态栏由 SpringBoard 远程渲染， 观感一致。

NoHomeIcons16

  1. 主屏（所有页）不显示任何 App 图标，只剩壁纸、小组件与搜索；Dock 保留
  2. 机制：纯视图层隐藏 —— SBIconListView -layoutIconsNow 后对每个 SBIconView 设 alpha=0 + 禁交互（视图经 -iconViewForIcon: 取得），-layoutSubviews 兜底重压。 不写 IconState，卸载即恢复原布局
  3. 锁定「新下载的 App = 仅 App 资源库」：hook NSUserDefaults -boolForKey: / CFPreferencesGetAppBooleanValue，读取 SBHomeAutomaticallyAddsNewApplications 时恒返回 NO，改 plist 或第三方工具无效
  4. 移除「设置 → 主屏幕」入口：设置根列表由 PreferenceManifests.bundle 的 Mach-O 生成（无 plist 可改）， 故在 PSUIPrefsListController -specifiers 层过滤 （该条 detail=DBSHomeScreenPhoneListController，没有 bundle 属性）
  5. 实测：手工把图标写进 iconLists 后界面不可见（hiddenViews=1）， 多任务 RecentAppLayouts 正常累积；设置根列表 32 → 31 项

⚠️ 0.6.0 曾用 SBIconModel -isIconVisible: 实现，会把多任务一起废掉 （上滑只剩 1 个卡片）—— 该判断被 SBRecentAppLayouts 共用，已弃用。 停用开关：/var/mobile/Library/com.xu.nohomeicons/disabled。 注入 SpringBoard + 设置两个进程。

Re:Scale Fixed 440（当前推荐）

  1. 固定 440×956pt（1320×2868 @3x，iPhone 18 Pro Max 6.9"），装完 respring 一次即全局生效， 没有设置界面、不需要点确认
  2. 复用原版 ReScale.dylib（by Sniper_GER）字节完全未改： RootHide trustcache 只认已登记 CDHash，自己编译/重签的 dylib 注入 backboardd 会被 amfid 拒绝 → 崩溃循环 → 看门狗。分辨率靠 postinst 写死偏好 （canvas_width=1320 / canvas_height=2868 / confirmedResolution=true）实现
  3. 键盘 414→440 修正内联在 ReScaleKB（行为级重写，非指令 patch）
  4. guard 标记 chflags uchg 锁死：原版 dylib 靠 /Library/dpkg/info/tf.festival.rescale2.list 决定装不装 hook， 缺了会静默失效（分辨率无声回落），故设为不可删
  5. 自带自检 /usr/bin/rf_check（15 项）与自愈守护 com.xu.rescalefixed.heal：开机 / userspace reboot 自动补文件， respring 后 ≤2 分钟补齐；仅"确实修了东西"时才重启一次 backboardd 让画布重读（10 分钟防抖）
  6. 与原版及旧重打包版互斥： Conflicts / Replaces: tf.festival.rescale2, com.xu.rescalekb440fix, com.xu.rescale2plus

⚠️ postinst 绝不重启任何系统进程（dpkg 事务里 kill backboardd 会进 spawn 循环 → 看门狗，已踩过两次）。装完由系统触发一次 respring 即生效。 自愈守护真的修复文件时会重启一次 backboardd，表现为屏幕闪一下，属预期。

Re:Scale 2 Plus（历史版本）

  1. 原版 Re:Scale 2（tf.festival.rescale2 1.0.5-1 by Sniper_GER）的完整重打包： 四个 dylib + 设置面板原样保留
  2. 1.0.5-3 起把 440 键盘修正直接 patch 进 ReScaleKB.dylib：它的三个尺寸 hook 里都在做 CGRectInset(bounds, padding, 0)，把 440 宽缩成 414； 把那处加载 padding 的 ldur d4, [x29, #-0x90] 改成 movi d4, #0， 宽度就等于屏幕宽（三处 patch：0x7540 / 0x7730 / 0x7920，arm64e 切片）
  3. 包内**不再有** ZZReScaleKB440Fix.dylib —— 少一层 hook、少一次注入
  4. 与原版互斥：Conflicts / Replaces: tf.festival.rescale2

⚠️ ReScale2 是闭源二进制，这是指令级 patch，位置与字节见 rescale2/README-440patch.md。改这个文件踩过一次安全模式： dyld 初始化阶段绝不能调 +[UIScreen mainScreen]，尺寸计算必须留到方法调用时。
